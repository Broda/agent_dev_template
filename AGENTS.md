# Master Template Dispatcher

This repository starts in brainstorming mode and can be finalized in place into development mode.

Read `MODE.md` first.

- If `MODE.md` says `brainstorming`, follow `brainstorming/AGENTS.brainstorming.md`.
- If `MODE.md` says `development`, follow `development/AGENTS.development.md`.

Do not mix the two rule sets in one task.
